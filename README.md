# 鹈鹕的兜风日

一个轻松的骑行主题动画网页：鹈鹕踩着自行车，在阳光和微风中向前骑行，路边景物与落叶缓缓掠过。

## 功能

- 双腿、脚踏和车轮同步运动，配合身体起伏、围巾飘动和眨眼。
- 支持暂停／继续，以及 0.5×～2× 骑行速度调节。
- 路面与远景以不同速度移动，落叶随风翻转，增强骑行的空间感。
- 适配桌面和手机，尊重系统的减少动态效果设置。

## 使用

用现代浏览器直接打开 `index.html` 即可，无需安装依赖或构建。首次播放状态会遵循系统的减少动态效果设置，也可以手动点击播放按钮。

## 文件

- `index.html`：完整动画网页，包含内联 SVG、CSS 和 JavaScript。
- `pelican-bicycle.svg`：最初的静态插画，保留为原始素材；后续动画与视觉调整在网页中实现。

项目采用原生 HTML、CSS、SVG 和 JavaScript，通过 `requestAnimationFrame` 同步动画，无外部运行依赖。
